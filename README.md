# Suno MR Skill

## Language · 언어 · 言語

**[한국어](docs/README.ko.md) · [English](docs/README.en.md) · [日本語](docs/README.ja.md)**

유튜브 링크를 받아 보컬을 분리하고, MP3 반주를 Suno MCP에 업로드하는 에이전트 스킬입니다.

An agent skill for turning a YouTube link into an MP3 accompaniment and uploading it through Suno MCP.

YouTube リンクからボーカルを分離し、MP3 伴奏を Suno MCP にアップロードするエージェントスキルです。

The skill requires a connected Suno MCP and an agent host that supports local skills, shell commands, and MCP tools.

[Suno MCP setup](https://suno.com/mcp) · [Skill instructions](skills/mr/SKILL.md)
